# VAPT Assessment Evidence Directory

This directory stores sanitized screenshots, proof-of-concept request logs, and evidence captures.

## Guidelines
- Do NOT commit sensitive user credentials, actual session tokens, or unredacted PII.
- Place screen captures (e.g. `sqli-burp-repeater.png`) here to reference within finding items.
- All raw scan logs are stored in `output/` (which is gitignored).
